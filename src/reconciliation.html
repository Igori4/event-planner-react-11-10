      Чому порівняння саме таке
      
    
        Повне перетворення одного дерева на інше має складність порядку O(n³).
        Для тисячі елементів це надто дорого. React використовує евристику O(n)
        з двома припущеннями: елементи різного type дають різні дерева, а
        key підказує, які діти стабільні між рендерами.
        Алгоритм — деталь реалізації. Навіть якби React щоразу викликав усі компоненти,
        на екрані лишився б той самий результат: у DOM потрапляють лише відмінності за цими правилами.
        Ключ має бути стабільним, передбачуваним і унікальним серед сусідів.
